# Project Schieferwald — Pitch Bible

> *An unnamed outcast navigates a quarantined borderland where archaic siege-industrialization violently collides with parasitic, vengeful folklore.*

A narrative-first **world and story bible** for an original dark-fantasy setting. The scope is a single contained region, **the Schieferwald (Slate-Weald)**: a mountain valley sealed off from a wider war after a catastrophic siege.

**Inspired by** the *Mirrorworld* (*Reckless*) novels by Cornelia Funke. This is an **original IP**. It uses no names, characters, places or terms from those books. See [`decisions/001-ip-nomenclature.md`](decisions/001-ip-nomenclature.md).

---

## Scope

This repository covers **narrative, setting, pillars and visual direction only**.

| In scope | Out of scope (separate game project) |
| :--- | :--- |
| Core pillars, tone, visual style | Genre, core loop, primary player verb |
| World rules: cosmology, curses, relics | Stats, progression, balancing |
| Region, factions, locations | Level design, encounter design |
| Characters, plot, dialogue samples | Quest scripting, branching implementation |
| Concept art and art prompts | Production art pipeline |

World systems are written as **in-world rules** (cause, progression, cost, visible signs), never as mechanics. That keeps the bible usable for any genre the game project chooses.

The final deliverable (v1.0) is the bible itself plus a **handoff brief** for the game project.
